## Cache File Location

~/Library/Application Support/YandexMusic/ipc_track_cache.json

## How to Update Cache

The cache file is automatically created at:
~/Library/Application Support/YandexMusic/ipc_track_cache.json

To add more track mappings, edit this JSON file:
{
  "tracks": {
    "TRACK_ID": {
      "title": "Track Title",
      "artist": "Artist Name",
      "album": "Album Name",
      "duration": 180,
      "genre": "Genre"
    }
  }
}

## Finding Track IDs

1. Open Yandex Music desktop app
2. Right-click on the track → Share → Copy track ID
3. Add the track ID and metadata to the cache
